# 0001. Stack va MVP chegarasi

- Sana: 2026-11-11
- Holat: Qabul qilindi (loyiha egasi tasdiqladi)

## Qaror

1. **Stack:** Next.js 16 + TypeScript + Tailwind 4 + Supabase + Vercel (spetsifikatsiya 14-qism).
   Alohida backend servis MVP'da yo‘q.
2. **MVP chegarasi:** onlayn to‘lov (depozit), Telegram Mini App, floor plan editor, marketing,
   sharhlar va AI — Phase 2 va undan keyin.
3. **Kirish:** telefon raqami + SMS kod (Supabase Send SMS Hook + mahalliy provayder, masalan Eskiz).
4. **Xarita:** Yandex Maps API (kalit domen bo‘yicha cheklanadi; litsenziya shartlari Sprint 5'da tekshiriladi).
5. **Region:** Supabase Frankfurt (eu-central-1). 2026-yil mart o‘zgartirishlaridan keyin oddiy shaxsiy
   ma'lumotlar uchun majburiy lokalizatsiya bekor qilingan, Germaniya soddalashtirilgan uzatish
   ro‘yxatida. Ishga tushirishdan oldin yurist tekshiruvi kerak.
6. **MVP rollari:** Owner, General Manager, Administrator, Host. Qolgan 4 rol bazada tayyor, Phase 2'da yoqiladi.
7. **Kontent tillari:** interfeys uz/ru/en; restoran tavsifi uz va ru majburiy, en ixtiyoriy.
8. **Obuna:** pilot davrida bepul, keyin qo‘lda hisob-faktura.

## Sabab

Bir kishilik jamoa uchun eng tez va xavfsiz yo‘l: kam qism, kuchli baza qoidalari, keyin kengaytirish oson.
